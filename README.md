## Linux Gnome Duo
a gnome extension that achieves the same folding effect as the iPhone Duo,calculate the opening and closing angles on a non-MacBook laptop using radar or camera.
### preview

https://github.com/user-attachments/assets/2fb03812-6c76-407d-ba0c-07aac362981c

### setup

* install

  ```shell
  ./setup.sh
  # then relogin on wayland
  ```

* config

  > [!note]
  >
  > If the mic is at the top of your screen, you can set Detection Method to `Sonar` in Settings (default is `Camera`).
